# Чек-лист проекта: Метро для Android — регрессия

> Итоговый проект (спринт 4). Мобильная регрессия после рефакторинга и решение о релизе: функциональные и регрессионные проверки, оценка рисков, Conditional Go.

🔗 Интерактивная версия: https://ikqavscode-afk.github.io/qa-test-documentation/checklists.html?p=sprint4

## Паспорт

| | |
|---|---|
| **Объект тестирования** | Мобильное приложение «Метро» для Android v3.6 (рефакторинг с v2.13): карта схемы, маршрут, история, настройки. |
| **Направленность** | Регрессионное тестирование; Мобильные факторы: ориентация, жесты, сеть, прерывания; Решение о релизе (Go/No-Go); Трассировка проверок и багов |
| **Окружение** | Android 9.0, 1080×1920, эмулятор и смартфон; приложение v3.6 |

**Что проверялось:**

- Построение маршрута, станции и их карточки
- История и временной интервал маршрута
- Смена ориентации экрана и жесты
- Сеть, установка и обновление, тёмная тема

**Не проверялось:**

- iOS
- Несколько версий Android и устройств
- Нагрузочное тестирование
