# Чек-лист проекта: Mesto — редактирование профиля

> Спринт 1. Первое знакомство с циклом ручного тестирования: от чтения требований до регрессионных кейсов и баг-репортов, связанных с кейсами.

🔗 Интерактивная версия: https://ikqavscode-afk.github.io/qa-test-documentation/checklists.html?p=sprint1

## Паспорт

| | |
|---|---|
| **Объект тестирования** | Веб-приложение Mesto: главная страница и окно редактирования профиля. |
| **Направленность** | Функциональное тестирование; Регрессионное тестирование; Валидация полей формы; Оформление баг-репортов |
| **Окружение** | Windows 10, Яндекс Браузер, веб-приложение Mesto |

**Что проверялось:**

- Окно редактирования профиля: открытие, закрытие, поля, сохранение
- Валидация «Имя» (2–40 символов) и «Занятие» (2–200 символов)
- Активность кнопки «Сохранить»
- Баги, найденные кейсами (MestoBug1–9), с приоритетами

**Не проверялось:**

- Автоматическое тестирование
- Карточки мест: добавление, лайк, удаление, просмотр
- Кроссбраузерная проверка
