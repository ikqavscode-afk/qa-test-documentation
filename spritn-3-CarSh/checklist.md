# Чек-лист проекта: Каршеринг — форма бронирования

> Спринт 3. Тестирование вёрстки и логики сложной формы: чек-листы по характеристикам элементов, кроссбраузерность, окна оплаты и добавления карты.

🔗 Интерактивная версия: https://ikqavscode-afk.github.io/qa-test-documentation/checklists.html?p=sprint3

## Паспорт

| | |
|---|---|
| **Объект тестирования** | Форма бронирования каршеринга в «Маршрутах» (тариф «Повседневный») и иконки машин на карте. |
| **Направленность** | Тестирование вёрстки; Кроссбраузерная проверка; Валидация полей карты; Логика кнопки «Забронировать»; Анализ серых зон требований |
| **Окружение** | Firefox 148 / Windows 10 / 1920×1080; Y-браузер / macOS / 800×600 |

**Что проверялось:**

- Форма бронирования, блок тарифа, поля «Права» и «Способ оплаты»
- Окно «Машина забронирована», иконки машин на карте
- Окна «Способ оплаты» и «Добавление карты» (номер карты, код)

**Не проверялось:**

- Другие тарифы
- Расчёт расстояния и времени на кнопке
- Окна подтверждения отмены (проверки пропущены)
