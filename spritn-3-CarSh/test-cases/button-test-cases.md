# Тест-кейсы: логика кнопки «Забронировать»

**Предусловия:** открыт тестовый стенд, в поле «Откуда» введено «Хамовнический вал, 18», в «Куда» — «Усачева, 3», выбран режим «Свой», вид транспорта «Каршеринг».

| ID | Сценарий | Ожидаемый результат | Статус | Баг |
|---|---|---|---|---|
| Т156 | Все обязательные поля заполнены | Кнопка «Забронировать», по клику открывается окно «Машина забронирована» | ✅ Passed | — |
| Т157 | Не заполнено «Права» | Кнопка «Добавить права и забронировать», по клику открывается окно «Добавление прав» | ❌ Failed | Б33 |
| Т158 | Не заполнен «Способ оплаты» | Кнопка «Добавить оплату и забронировать», по клику открывается окно «Добавление карты» | ❌ Failed | Б34 |
| Т159 | Удалены «Откуда» и «Куда» при заполненных правах и оплате | Кнопка «Забронировать», по клику «Машина забронирована» | ⛔ Blocked | Б14 |
| Т160 | Все поля пустые | Кнопка «Добавить права и забронировать», по клику окно «Добавление прав» | ⛔ Blocked | Б14 |

Связанные серые зоны: [GZ8](../test-analysis/gray-zones.md).
