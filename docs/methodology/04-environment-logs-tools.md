# Окружение, логи и инструменты

## Окружение в баг-репорте
- Десктоп: ОС + версия, браузер + версия.
- Мобильные: модель устройства, версия ОС, браузер/приложение.
- Кроссбраузерность: один и тот же сценарий проверяют в нескольких браузерах — баг может воспроизводиться только в одном.

## Логи
Уровни сообщений, от подробных к критичным: `debug` → `info` → `notice` → `warn` → `error`.
В баг-репорт прикладывают фрагмент лога с ошибкой (без личных данных).

## Инструменты
- **DevTools браузера**: вкладки Elements, Console, Network — проверка запросов, ответов и ошибок.
- **Баг-трекер** (здесь — GitHub Issues): метки серьёзности и приоритета, доска статусов.
- **Заметки/Markdown**: чек-листы и тест-кейсы в виде текста.
