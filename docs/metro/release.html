Симулятор решения о релизе

Отметьте баги, которые будут исправлены до релиза. Решение рассчитывается по рискам: серьёзность, наличие обхода и влияние на основные сценарии. Модель условная.

Правила: открытый critical без обхода — No-Go; открытые critical с обходом — Conditional Go; только major — Go с известными ограничениями.
