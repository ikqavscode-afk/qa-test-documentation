# Матрица мобильных проверок

Что специфично именно для мобильного приложения и проверяется регрессией:

| Группа | Примеры проверок | Чек-лист |
|---|---|---|
| Ориентация | сохранение масштаба, положения карточек, расположение полей ввода | Ф16–Ф23, Р15–Р16 |
| Жесты | свайп по карте и карточкам, пинч и спред | Р9–Р14 |
| Сеть | переключение 3G/LTE/Wi-Fi, обрыв, авиарежим | Ф24, Р3–Р5 |
| Прерывания | входящий звонок, push, переключение приложений | Р6–Р8 |
| Режимы устройства | энергосбережение, низкий заряд, блокировка экрана | Р20–Р22 |
| Установка | чистая установка, обновление с сохранением истории | Ф1, Р18–Р19 |
| Системные настройки | масштаб интерфейса, тема, язык | Р17, Р23–Р25 |

> Все сети, ориентации и режимы устройства — это независимые факторы. Их сочетания (например, поворот экрана при отсутствии связи) — кандидаты для следующей итерации.
