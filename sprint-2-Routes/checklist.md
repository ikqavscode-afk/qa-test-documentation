# Чек-лист проекта: Маршруты — валидация и расчёт

> Спринт 2. Тест-дизайн на практике: классы эквивалентности и границы, проверка валидации полей и формулы расчёта стоимости и времени поездки.

🔗 Интерактивная версия: https://ikqavscode-afk.github.io/qa-test-documentation/checklists.html?p=sprint2

## Паспорт

| | |
|---|---|
| **Объект тестирования** | Форма построения маршрута «Маршрутов»: поля времени («Часы», «Минуты»), адреса («Откуда», «Куда»), расчёт для собственного автомобиля. |
| **Направленность** | Тест-дизайн (классы эквивалентности, граничные значения); Позитивное и негативное тестирование полей; Проверка расчёта по формуле t = S / V |
| **Окружение** | Google Chrome 145, Windows 10 |

**Что проверялось:**

- Валидация часов (0–23) и минут (0–59)
- Валидация адресов из фиксированного списка, обрезка пробелов
- Расчёт времени и стоимости по интервалам времени суток

**Не проверялось:**

- Другие виды транспорта
- Режимы «Оптимальный» и «Быстрый»
- Кроссбраузерность
