# Маршруты — тестовая документация (демо)

Демо-версия тестовой документации по приложению «Маршруты» (Спринт 2).

**Объект тестирования**
- валидация полей времени («Часы», «Минуты») и адресов («Откуда», «Куда»);
- расчёт стоимости и времени поездки на собственном автомобиле: `t = S / V`, стоимость = S × цена за км, скорость зависит от времени суток.

**Применённые техники тест-дизайна:** декомпозиция, классы эквивалентности, граничные значения, позитивные и негативные проверки.
