# Декомпозиция и классы эквивалентности (демо-версия)

Показаны поля «Часы», «Минуты», «Откуда» и сценарии расчёта. Поле «Куда» построено аналогично «Откуда».

## 1. Декомпозиция: поле «Откуда» (пример)

- Валидное значение из списка
- Невалидное значение
- Удаление пробела до / после / до и после валидного значения
- Обязательность заполнения (пусто / заполнено)
- Валидация: сообщение об ошибке, красная рамка
